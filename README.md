# 星愿奇境 · Starwish Wonderland

可交互的 Three.js 3D 童话乐园。

- 城堡、旋转木马、飞椅、摩天轮、海盗港、糖果小镇、星际花园与盛夏日落音乐舞台。
- 第一／第三人称、步行／飞行、自由俯仰与设施乘坐视角。海盗船随悬架摆动，可登船体验。
- 午后、夕阳与暖夜，彩色烟花及间歇彩带。
- 默认配乐为阿冗《与我无关》，首次操作后循环播放。乐队有分角色走位、脚步、独奏和鼓组加花，动作与灯光响应音乐。可用本地MP4或音频替换；用户选取的替换文件仅在当前浏览器中读取，不会上传。

在线体验：https://xuyu666.github.io/starwish-wonderland/

拖动环顾、滚轮缩放；WASD移动，V切换人称，F切换飞行，Space/Shift升降。
